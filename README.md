# Chess.com-to-pgn
A simple, fast and easy-to-use tool that lets you download Chess.com games as PGN files with one click.

You do not need to navigate through your Chess.com game history. Enter a username select the required games and download them as a.pgn file.

✨ Features

⚡ One-click PGN downloading

👤 Download games from any public Chess.com username

📥 Export games in format

🎯 Simple and beginner-friendly interface

🚀 Fast and lightweight

💻 Works from your browser

🔒 No Chess.com password or account access required

📂 Use downloaded PGNs with chess analysis software such, as ChessBase, Lichess or other compatible chess tools

🛠️ How It Works

Enter a Chess.com username.

Select the games or date range you want.

Click Download PGN.

Your games are downloaded as a.pgn file.

Open the PGN in your chess analysis software.
